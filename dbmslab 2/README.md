# DBMS Assignment 2 – MySQL SELECT Queries

## 1. Problem Statement
To practice SQL SELECT queries and retrieve, filter, sort, and perform calculations on employee records using MySQL.

## 2. Approach
- Used SELECT to retrieve employee details.
- Applied DISTINCT and ORDER BY.
- Used aggregate functions like SUM, AVG, MAX, MIN and COUNT.
- Applied string functions like UPPER, SUBSTRING, CONCAT, TRIM and LENGTH.
- Performed arithmetic calculations and salary conversions.
- Used queries to check and retrieve specific records.

## 3. Time and Space Complexity
- **Time Complexity:** Depends on the number of records, query type and indexes.
- **Space Complexity:** Depends on the data retrieved and intermediate results.

## 4. Sample Input / Output

**Query:**
```sql
SELECT UPPER(first_name)
FROM employees;
```

**Sample Output:**

```text
ELLEN
SUNDAR
NEENA
```
